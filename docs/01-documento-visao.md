# Documento de Visão

# Projeto

Inventário de Equipamentos de TI

---

## 1. Visão Geral

O Inventário de Equipamentos de TI é um sistema web desenvolvido para auxiliar equipes de suporte técnico no controle e gerenciamento de ativos de tecnologia da informação.

O sistema permitirá cadastrar equipamentos, usuários, departamentos, movimentações e manutenções, oferecendo uma visão organizada do parque tecnológico da empresa.

Este projeto será desenvolvido para compor um portfólio profissional, demonstrando conhecimentos em análise de requisitos, modelagem de banco de dados, desenvolvimento web e documentação técnica.

---

## 2. Problema

Em muitas empresas o controle dos equipamentos é realizado por planilhas ou processos manuais.

Esse modelo dificulta o acompanhamento da localização dos ativos, do histórico de manutenções e da responsabilidade de cada usuário, aumentando o risco de perda de informações e reduzindo a eficiência da equipe de suporte.

---

## 3. Objetivo

Desenvolver um sistema simples, intuitivo e organizado para controlar os ativos de TI de uma empresa.

O sistema deverá permitir:

- Cadastro de equipamentos;
- Cadastro de usuários;
- Cadastro de departamentos;
- Controle de movimentações;
- Registro de manutenções;
- Consulta rápida das informações.

---

## 4. Público-alvo

O sistema foi pensado para pequenas e médias empresas que desejam organizar seus ativos de TI sem utilizar soluções complexas.

Também servirá como projeto demonstrativo para fins de estudo e portfólio profissional.

---

## 5. Escopo da Versão 1.0

A primeira versão contemplará:

- Cadastro de departamentos;
- Cadastro de usuários;
- Cadastro de equipamentos;
- Histórico de movimentações;
- Histórico de manutenções;
- Pesquisa de equipamentos;
- Dashboard inicial.
